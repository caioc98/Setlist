Abrir playlist do Spotify

O login do Spotify precisa da página aberta por http ou https — abrindo o arquivo direto (file://) ele não funciona. Publica a pasta no GitHub Pages, ou roda npx serve aqui dentro e abre http://127.0.0.1:3000. Enquanto isso dá pra usar o Importar.

Uma vez só: o app precisa de um Client ID seu (grátis, uns 2 minutos).

  1. Abre o Spotify Developer Dashboard e clica em Create app.
  2. Em Redirect URI, cola exatamente isto e clica Add:
  3. Marca Web API, salva e copia o Client ID da tela de settings.

Client ID salvo. Agora é só autorizar a leitura das suas playlists.
